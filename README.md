# Adventure Works Executive Summary Dashboard

## 📊 Project Overview

This project presents an **Executive Summary Dashboard built in Microsoft Power BI** using Adventure Works business data. The dashboard transforms business data into an interactive executive-level view of sales, customers, cities served, product categories, order status, and sales trends.

The dashboard is designed to help business stakeholders quickly understand overall performance and identify trends across products and locations.

## 🎯 Business Objective

The objective of this project was to create a clear and interactive dashboard that provides a high-level overview of Adventure Works' business performance.

The dashboard helps stakeholders:

* Monitor key business metrics
* Analyze sales by product category
* Track sales trends over time
* Compare sales performance across cities
* Review product-level order information
* Understand order status
* Analyze order quantities across product categories

The dashboard includes a **Sales Trend & Forecast** visualization that allows users to examine sales performance over time and identify patterns in the available data.

The displayed trend includes monthly sales information for **February 2023 through April 2023**.

## 💡 Key Insights

Based on the dashboard:

* **Mountain Bikes** have the highest order quantity among the displayed product categories, with 30 orders.
* **Road Bikes** follow with 25 orders, while **Touring Bikes** have 21 orders.
* The dashboard records a total of **92 product orders** across the displayed categories.
* Adventure Works serves customers across **14 cities**.
* The dashboard provides visibility into different order statuses, helping stakeholders monitor processing, shipped, and cancelled orders.
* The sales trend visualization provides a view of changes in sales across the available months.
